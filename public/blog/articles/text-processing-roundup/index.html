清洗与整理：先把文本弄干净#

批量改术语、统一字段名，交给支持正则的🔧 文本替换 ，一次到位。从 PDF 复制来的字间空格、全角空格，用🔧 空格格式化工具 一键清理；段首该缩进的没缩进、缩进深浅不一，🔧 文本缩进格式化工具 统一样式。中英混排里全角逗号和半角逗号混着用，🔧 全角半角转换工具 按需全转。英文段落要在全大写、全小写、首字母大写之间切换，🔧 大小写转换 随点随换；整篇小写的英文稿，🔧 句首大写工具 按句子自动补大写。改 API 命名风格，🔧 命名格式转换 在 camelCase、snake_case、kebab-case 之间互转，不用手抠下划线。想知道一段话倒着念什么样、或做个回文测试，🔧 文本倒置工具 整个翻过来。最后兜底的是🔧 行操作工具 ，去重、排序、删空行、加行号，一堆日志先过一遍再交给下一站。

格式转换：换一副骨架#

网页正文想存成纯文本，🔧 HTML转纯文本工具 把标签样式全部剥干净。逗号、制表符分隔的数据要贴进文档，🔧 文本转表格工具 直接变出可复制的表格。从一大段里抽出邮箱、手机号、URL、日期，🔧 文本提取器 一把抓全。章节编号在罗马数字和阿拉伯数字之间来回换，🔧 罗马数字转换 即输即得；合同金额要大写、章节要「一二三」，🔧 中文数字转换器 双向都能转。

中文向：拼音与成语#

给课文、生词表加注拼音，🔧 拼音转换工具 声调齐全，多音字也能按词消歧。写作卡词想找个贴切的成语，🔧 成语词典接龙 查释义顺便还能玩接龙。

写作向：统计、转义与参考文献#

交稿前心里没底，🔧 文本统计分析工具 把字数、词频、可读性一次报齐。文本要塞进各类系统又怕特殊字符闹脾气，🔧 文本转义工具 统一转义再粘贴。论文参考文献最磨人，🔧 GB/T 7714引文生成器 按国标格式直接生成，条目字段填好就出标准样式。
