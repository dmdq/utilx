Chrome 才有的文件魔法：批量重命名，和永不上传的手机号查询

效率工具
2026-11-04有条工具团队

批量重命名：浏览器里直接改文件夹里的文件#

🔧 批量重命名 用的 File System Access API（Chrome/Edge 86+，需 HTTPS）——授权一个文件夹后，浏览器真的能按你的规则改里面文件的名字。Firefox/Safari 暂不支持，页面顶部的琥珀色兼容条把这一点写得直白，用不上的浏览器会看到明确提示而不是点了没反应。

五条规则按顺序叠加，覆盖改名 95% 的需求：查找替换（字面量，可区分大小写）、正则替换（/pattern/flags 写法，支持 $1 捕获组，非法表达式红字不应用）、加前缀/后缀（聪明地加在扩展名之前）、序号模板（{n} 起始位宽补零、{name} 主名、{date} 文件日期）、大小写转换。

最让人安心的是先预览后执行：改名前列出"原名 → 新名"对照（变化部分高亮），撞名检测双保险（新名和目录内其他文件冲突、或互相冲突都会红行禁用执行按钮），执行后还能撤销——改完发现不对，点撤销逐个回退。安全底线是清洗非法字符与保留扩展名。典型用途：手机照片批量按日期命名（IMG_{date}_{n}）、剧集补零、去掉下载后缀 (1)。

手机号归属地：号码不出电脑#

归属地查询类产品众所周知的代价：你把一串手机号发给别人的服务器。🔧 手机号归属地查询 反着做——内置公开号段分配库（运营商 3 位网号表 + 常见城市级前缀，截至 2025 年），最长前缀匹配出省市，号码在本地查，零网络请求。单号查、批量粘贴（每行一号，去重出表）、脱敏显示（138****5678）都是为实际工作流准备的：运营核名单、HR 筛简历电话、二手平台看号段。

诚实边界同样显著：结果以号段首次放号城市为准，携号转网普及的今天，归属地只能说明"这号最初发给哪"——页面对这点专门写了一段科普。查不到的新号段降级标"未收录"，不猜。

两件工具的共同主题：浏览器能力的边界内做满#

这两件都不属于"纯公式"类小工具——它们调用的是现代浏览器的本地能力（文件系统、本地数据库匹配），这也是纯本地站能持续扩张的方向：过去只有桌面软件干的事，现在标签页里就能干，而且数据不出设备。同主题的老朋友还有视频裁剪与音频拼接（媒体三件套），新访客从这三个页面就能理解本站的立场。

常见问题#

批量重命名支持子文件夹吗？#

本版可递归列出子目录文件做预览，但执行改名只作用于顶层文件（子目录内改名涉及权限链复杂度，页面注明并计划后续开放）。

撤销记录会保存吗？#

不会。撤销只在本次页面会话有效，刷新即丢——这是安全设计：避免隔天误撤销造成困惑。重要批量操作前自己留个备份。

号段库多久更新一次？#

静态收录截至 2025 年公开分配，新放号段（尤其 19x）可能滞后，页面页脚注明。需要绝对准确：运营商官方 App 或工信部码号系统。
