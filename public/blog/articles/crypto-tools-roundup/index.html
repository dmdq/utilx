AES、国密、Ed25519：19 件加密与哈希工具大盘点

效率工具
2026-11-08有条工具团队

对接支付渠道要验签，用户注册的口令不能明文落库，等保整改通知点名要用国密——加密和哈希的活儿散在各个岗位，隔一阵不用就得现查，术语还特别容易混。站点的加密哈希工具攒到 19 件，这篇按「对称加密、非对称与签名、口令哈希、校验与杂项」四组理一遍，用的时候按图索骥。

对称加密：一把钥匙管两头#

配置文件里的 API 密钥要落盘，先交给🔧 AES加密 包一层，再放对象存储才踏实。拿到同事发来的密文，用🔧 AES解密 配上同一把钥匙还原原文，交接文档不用口口相传。移动端性能紧张又要带认证的加密，🔧 ChaCha20-Poly1305加密 是 TLS 1.3 里的常客，低端设备跑它不费劲。等保合规点名国密，🔧 国密算法工具 把 SM2、SM3、SM4 一站测完。

非对称与签名：公钥锁、私钥开#

接入开放平台前先造密钥，🔧 RSA密钥生成 出一对 2048 位密钥，公钥上传平台、私钥本地收好。给合作方传敏感字段，用🔧 RSA加密 拿对方公钥锁上再发。收到渠道回传的加密数据，🔧 RSA解密 用自己的私钥打开。回调通知要防伪造，🔧 RSA签名验签工具 先验签再走业务，假回调拦在门外。对签名长度敏感的物联网设备，🔧 ECDSA椭圆曲线签名 用更短的密钥达到同级强度。新式 SSH 密钥和现代协议首选🔧 Ed25519签名工具 ，算得快还不容易用错。双方要在不安全信道上商量出同一把对称密钥，🔧 Diffie-Hellman密钥交换 就是干这个的老前辈。

口令哈希：库里只存摘要#

新用户注册入库，🔧 Bcrypt加密 自动加盐做慢哈希，拖慢暴力破解。登录时用🔧 Bcrypt验证 比对哈希结果而不是比对明文，库里泄了也不裸奔。想让 GPU 也啃不动，🔧 Scrypt哈希生成器 用内存难度再加一堵墙。新项目可以直接上🔧 Argon2哈希工具 ，密码哈希竞赛的冠军方案。

校验与杂项：小件补齐缺口#

固件升级包传完先核🔧 CRC校验计算器 ，确认传输没出错，刷机失败多半坏在这一步。一把主密钥要派生多把子密钥，🔧 HKDF密钥派生器 按标准流程走。嫌 MD5 太弱又想要速度，🔧 BLAKE2哈希计算器 两头兼顾。对接比特币地址这类还在用老算法的协议，🔧 RIPEMD-160哈希计算器 随时能补位。

19 件加密哈希工具全部在浏览器本地运行，密钥和明文都不出浏览器。加密只是防护的一道门，证书、响应头这些外围自查，收录在隐私防护套装专题里，值得配着一起看。
