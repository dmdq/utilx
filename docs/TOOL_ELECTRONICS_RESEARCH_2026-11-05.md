# 电子元器件行业选品调研（2026-11-05，第五轮·商业合作向）

> 背景：用户有商业合作方经营**电子元器件销售（电容器、传感器、IC 芯片、PCB 板）+ 集成电路测试代工**，客户群为**工程师（选型设计）与维修人员（换件修复）**。本轮目标：扩展能吸引这两类人群的工具，为后期导流合作铺路。
> 方法：站内盘点（注册表 780 款碰撞检测 + 画像底账 + collections）→ WebSearch 12 组竞争查询 → 按"真空/可差异化/饱和/不可行"四档判定 → 分批落地路线。

## 五、导流机制设计（需用户拍板，注意"无广告纯本地"品牌边界）

站点品牌承诺是**无广告、数据不上传**，商业化导流建议用以下形态（而非广告位）：

1. **选型建议即导流**：计算结果区给出规格口径与替代料提示（如"450V AC CBB61 风扇电容"），这是内容的自然组成部分，不是广告；后续与合作方对齐"哪些计算结果带商品口径"；
2. **「元器件合作伙伴」栏目**：相关工具页与 3 个新专题页尾放一个显著的友情位（合作方店铺入口 + IC 测试服务入口），明确标注"合作伙伴"而非"广告"，先小范围挂在电子类工具页试水；
3. **测试线信任背书**：Cpk/GR&R/DPPM 工具页的 SEO 区可写"第三方 IC 测试流程中如何使用本工具"的场景内容，服务入口后置到文末；
4. **节奏建议**：先让工具上线积累搜索流量（1-2 个收录周期），确认电子类词有排名后再挂合作位——过早挂位影响收录与品牌。

## 六、规格锚点（供后续写规格书，查表类先自核标准）

- **4-20mA**：工程量 = L + (I−4)/16 × (H−L)；PLC 档位表（西门子 5530~27648 / 三菱 FX 0~4000 等）**以各厂手册为准自核**，页面注明"接线以变送器手册为准"；
- **NTC**：Rt = R25·exp(B·(1/T − 1/298.15))，T 为开尔文；宽温区用 Steinhart-Hart：1/T = A + B·lnR + C·(lnR)³；B 值口径（B25/50、B25/85）要区分；
- **PT100**（IEC 60751 / Callendar-Van Dusen）：t≥0：R=R0(1+At+Bt²)；t<0 加 C(t−100)t³；A=3.9083×10⁻³、B=−5.775×10⁻⁷、C=−4.183×10⁻¹²；K 型热电偶用 NIST ITS-90 分度表内嵌插值（勿手造表，**以 NIST 官方表自核**）；
- **电解电容寿命**：L = L0 × 2^((T0−T)/10)，纹波修正各家模型不同（江海/TDK 口径）——页面按"估算"措辞并给多厂公式注记；
- **热阻**：Tj = P×(Rjc+Rcs+Rsa)+Ta；判定线 Tj < 125℃（保守）/150℃（上限）；导热硅脂 Rcs 典型 0.2~0.5 ℃/W、导热垫另计——典型值注记"以规格书为准"；
- **电机电容**：运转 C(µF)=1950×I/(U×cosφ)、启动 C(µF)=3500×I/(U×cosφ)、经验法每 100W 取 4-6µF；耐压 ≥1.5~2.2 倍工作电压（常用 450V AC）；双值电容（CBB60 J 带启动+运转双容）单独说明——**公式系数各家资料有出入，页面双轨并列并注明经验性**；
- **I2C 上拉**（TI SLVA689）：Rp(min)=(VDD−VOL)/IOL、Rp(max)=tr/(0.8473×Cb)；速览 100kHz≈4.7k、400kHz≈2.2k~4.7k；
- **晶振**：CL = C1·C2/(C1+C2) + Cs（Cs 常取 3~5pF）；C1=C2 时各 ≈ 2(CL−Cs)；ppm = (f−f0)/f0×10⁶；
- **E 系列**：E24=10^(n/24) 系，组合替代=两只串联（R1+R2）/并联（R1R2/(R1+R2)）双重搜索最近值；
- **DPPM**：DPPM=不良数/总数×10⁶；滚动良率=∏各站良率；置信上限（60%/90%）按二项分布单侧上限（TI 口径）；
- **Cpk**：Cpk=min(USL−μ, μ−LSL)/(3σ_短期)，σ_短期=R̄/d₂ 或 S̄/c₄；Ppk 用样本 σ；判定 <1.0 不足 / 1.0-1.33 有条件 / ≥1.33 充足；
- **GR&R**（AIAG MSA）：%GRR=6σ_GRR/(USL−LSL)×100%，<10% 可接受 / 10-30% 有条件 / >30% 不可接受；**展开式与 d₂ 系数以 AIAG 手册自核**；
- **PCB 线宽**（IPC-2221 显式式）：I = k·ΔT^0.44·A^0.725，k=0.048（外层）/0.024（内层）；**注明 IPC-2152 为更保守的现行标准，本公式用于快速估算**；
- **丝印 date code**：YYWW 为主流（2547=2025 第 47 周），也有 YYMMDD/周批混合——页面按"常见规则"措辞，前缀厂商表标注"厂商并购频繁，仅供线索"。

## 七、风险与注意

1. 查表类数据完整性是 SSR 500 高发区（公差页 IT8 前车之鉴）——分度表内嵌数据必须 SSR 全参数探测；

4. 丝印解读器定位严格控制在"教学线索"，不做全量反查承诺，避免与芯查查正面竞争；

### 建议一：画像补缺后的「复利」用法

本批已把 `hardware-engineer`（硬件/电子工程师，11 任务）与 `electronics-repairer`（电子维修技师，9 任务）挂进 personas 底账，31 画像，「按职业找工具」页自动带出 2 个新职业详情页。后续用法：

1. **断档即需求**：电子类后续选品从这两画像跑 `npm run persona-audit` 找断档任务（合作方客户群的任务清单本身就是需求清单）；
2. **客户 FAQ 即选品输入**：与合作方对齐他们的客户最常问的问题（工程师选型困惑 / 维修工换件困惑），直接转成画像新任务与新工具的输入源——这是比外部调研更准的一手数据；
3. **职业页吃长尾**：2 个新职业页天然承接"硬件工程师常用工具""电子维修工具箱"类长尾词，配合「按职业找工具」板块的既有 SEO 结构。

### 建议二：丝印「教学型」定位与合作方数据资产的升级路径

短期（已实施）：教学型解读器（date code 解读 + 前缀厂商线索）避开芯查查/smdmarking 的数据库垄断，吃"看懂丝印""date code 怎么读"信息型流量，定位严格不承诺反查。

**中期升级路径（合作深化时的差异化筹码）**：合作方做元器件销售 + IC 测试代工，日常经手大量真器件，手里天然沉淀丝印-型号对应关系（测试记录/来料记录）。若合作深化，可由**合作方提供其主营品类**（电容器、传感器、特定 IC 家族）的丝印对照精选数据集，站内做成「合作方验证库」查询功能并标注数据来源——这是纯爬取的竞品不具备的信任资产，且数据维护成本落在合作方业务范围内（他们本来就在管这些数据）。红线：不做全量反查承诺（维护成本无底洞），数据集只做精选品类。

### 建议三：导流三阶段节奏（守住「无广告纯本地」品牌边界）

| 阶段 | 时点 | 动作 | 形态 |
|---|---|---|---|
| **1. 上线积累** | 本批（已实施） | 12 工具 + 3 专题 + 2 画像上线；结果区给规格口径（选型建议即内容，如"450V AC CBB60"） | 无合作位，纯内容 |
| **2. 合作位试水** | 约 2-4 周后，看百度/Bing 收录与电子类词排名 | 在 3 个新专题页 + 相关工具页尾挂「元器件合作伙伴」栏（合作方店铺 + IC 测试服务入口） | 明确标注"合作伙伴"（非"广告"），外链 `rel="sponsored nofollow"`（SEO 卫生），先小范围 |
| **3. 口径对齐** | 排名稳定后 | 结果区选型口径与合作方现货 SKU 对齐（常用容值/封装现货提示）；IC 测试工具页尾放服务介绍段落 | 内容形态非横幅，百度统计看专题页→合作方点击率 |

三条红线贯穿始终：① 数据不上传不变（本地计算是品牌根基，也是对工程师人群最强的信任卖点）；② 不做弹窗/侧边栏广告位；③ 合作位必须与页面内容强相关（电容器导流挂电容相关页，不挂无关页）。
