## 四、规格锚点

**legal-doc-generator**：模板变量结构化（甲方/乙方/标的/期限/违约条款…），必填校验 + 空位用「____」占位；每模板附「使用提示」（如授权书需按手印、租房合同需附房产证复印件）；输出纯文本预览（等宽/宋体风格）+ 一键复制 + 打印（print CSS 只打正文）。**法律免责声明显著**（模板仅供参考，重大事项咨询律师）。模板文本参照市面通用范本口径，不发明条款。
**official-document-generator**：GB/T 9704-2012 口径：标题小标宋 22pt 居中、红色分隔线（发文机关标志下）、文号居中（〔2026〕N 号六角括号）、正文仿宋 16pt、成文日期右空四字；支持上行文/下行文眉首差异简化为单样式；输出 A4 打印。自核口径（查表类教训）。
**seal-maker-online**：Canvas 绘制：圆章（直径可调、弧形文字沿环排布、五角星中徽可选、内圈线）、椭圆章（两圈弧线）、字样（宋体/SimSun 口径标注字体可用性依系统）、导出 512×512 透明 PNG；**显著提示「仅供学习/排版预览，伪造公章违法」**。
