## 一、24 款主推清单

### PDF 编辑后半场（6 款，`[同行]` 证据最硬的一族）

四大 PDF 垂直站（Smallpdf/iLovePDF/TinyWow/PDF24）的热门功能，全部 pdf.js + pdf-lib 纯前端可实现；与站内已有的"PDF 合并拆分（文件级）"构成完整 PDF 工具家族。

**1. PDF 转图片**（高）——Smallpdf 独立分类、TinyWow 热门标签 Top；"pdf转图片"中文大词。pdf.js 逐页渲染 Canvas 导出 JPG/PNG。
**2. PDF 压缩**（高）——Smallpdf 热门第 6；扫描件/标书瘦身刚需。逐页渲染重建 + JPEG 质量分档。
**3. PDF 页面整理**（高）——iLovePDF"排列 PDF"整组功能；缩略图拖拽重排/删页/旋转/抽取。与站内文件级合并拆分互补。
**4. PDF 电子签名**（高）——Smallpdf 热门第 4"签署 PDF"。Canvas 手写签名 + pdf-lib 盖章定位到任意页。
**5. PDF 添加页码**（高）——iLovePDF/PDF24 独立页；竞争度中低、打印归档刚需。自定起始号/格式/位置。
**6. PDF 解除密码**（高）——TinyWow"Unlock PDF"热门；仅限已知密码的本人文件（合规提示内置）。

### 音视频原生能力（2 款，`[同行]`+`[词缺]` 双标签）

**7. 在线录屏**（高）——两路调研独立发现：JSON.cn 图片分类收录、国际 Loom 需求外溢。getDisplayMedia + MediaRecorder，存 WebM/MP4。
**8. 文字转语音 TTS**（高）——TTSMaker 类站月访千万级、"文字转语音在线"中文大词（短视频配音）。浏览器原生 speechSynthesis + 系统中文语音包，免费无云端。

### 个人事务打印族（4 款，`[词缺]`，隐私卖点）

**9. 身份证复印件排版打印**（高）——搜索首屏全是 Word 手动教程与需上传照片的在线工具；Canvas 按 85.6×54mm 标准卡排一页 A4，正反面本地合成，证件照不出浏览器。
**10. 会议桌牌批量生成**（高）——Canva/稿定要注册登录；粘贴名单→双面镜像排版→批量打印对折席卡。
**11. 节假日值班表生成器**（高）——供给全是登录型排班平台；复用站内法定节假日数据，成员×日期轮转+打印公示。
**12. 请假条/证明生成器**（高）——搜索结果是范文垃圾站；表单→规范模板→打印签字。

### 家庭账本族（2 款，`[词缺]`）

**13. 阶梯电价计算器**（高）——首屏只有政策解读文与"网上国网"App；内置主要省份分档电价规则表，输用电量出电费。
**14. 电动车充电成本计算器**（高）——"一公里几分钱"的购车决策问题无中文专门工具；电量×电价÷续航，可与站内油耗计算器联动对比。

### 电商运营族（3 款，`[词缺]`）

**15. 评论区抽奖工具**（高）——开奖必抽评论，供给是平台自带（限直播）或直播伴侣；粘贴名单→按用户去重/加权随机→开奖结果图。
**16. 淘宝标题组合生成器**（高）——淘系 30 字标题是运营每日动作，免费供给分散；核心词+属性词排列组合去重+30 字限流计数。
**17. SKU 规格组合生成器**（高）——颜色×尺码笛卡尔积上架刚需，现有为通用笛卡尔积工具非电商场景；生成规格 SKU 表导出 CSV。

### 开发者（4 款，`[词缺]` 3 + `[同行]` 1）

**18. 数据字典生成器**（高）——DDL 粘入→带字段注释的 Word/Excel/Markdown 数据字典；Screw（"数据库界的 Swagger"）需跑 Java，网页端空白，后端交付物高频。
**19. 正则可视化**（高）——Regexper/Regulex 全英文且国内访问不稳；正则→SVG 铁路图，与站内正则家族互链。
**20. SQL IN 条件格式化器**（高）——Excel 粘来的 ID 列表一键变 `IN ('a','b')`，运维/DBA 每日高频；现有小站无引号转义/数字识别/去重。
**21. htpasswd 生成器**（高）——OSCHINA 热门区标[新]；Nginx/Apache Basic Auth 刚需，复用站内 bcryptjs，附 nginx auth_basic 片段。

### 查询与转换（3 款，`[同行]`）

**22. 地图坐标转换**（高）——tool.lu 顶部推荐热词（与正则/时间戳并列）；GCJ-02/WGS84/BD09 火星坐标纠偏，LBS 开发必用，约百行纯算法。
**23. 成语词典/接龙**（高）——matools 热门榜第 19 位；内置成语词库 JSON，查询+接龙游戏双模式，学生作文高频。
**24. 元素周期表速查**（高）——BeJSON/JSON.cn 双站收录；实现成本极低的引流页，学生化学查询。
