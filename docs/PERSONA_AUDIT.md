## 使用规则

1. 每批工具上线后：先在 `src/data/personas.js` 把新工具挂到对应画像任务上，再跑本脚本刷新报告；
2. 新任务（发现新需求）直接往对应画像的 tasks 里加一条 tools: [] 的记录，它会自动进入断档清单；
3. 画像覆盖率 ≥90% 即"饱和"，选品跳过该画像；
4. 报告每次全量覆盖 PERSONA_AUDIT.md，如需历史请自行拷贝归档。
