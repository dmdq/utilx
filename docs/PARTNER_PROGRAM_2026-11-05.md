站方已完成：`src/data/partners.js`（数据开关）+ `src/components/PartnerLinks.vue`（渲染组件，外链固定 `rel="sponsored nofollow"`），并已挂载到上述 4 个专题页尾。**当前总开关关闭，页面上不渲染任何内容。**

上线动作（合作方提供信息 → 站方 10 分钟改完重新构建）：

1. 合作方提供：①店铺/官网链接（元器件供应）②测试服务介绍页链接（IC 测试代工）③两句以内的服务简介；

## 三、丝印验证库（阶段 3 升级路径，合作方数据资产变现）

竞品（芯查查/smdmarking 等）靠爬虫拼全量库；本站差异化是**「测试过才收录」的信任库**——只收合作方日常经手、验证过的品类，标注数据来源。合作方本就沉淀在测试/来料记录里的丝印-型号对应关系，是这条路的唯一门槛，也是护城河。

启动条件（满足其一即可谈）：合作深化意向明确；合作位点击率达标；合作方愿意指定专人按模板攒数据。

数据交付模板（Excel/CSV 均可，站方转换为站内查询格式）：

| 字段 | 说明 | 示例 |
|---|---|---|
| marking | 丝印原文（原样，含大小写） | L35C / A2sHb |
| category | 品类：capacitor / sensor / ic-family 名 | ic |
| family | 家族（IC 类必填） | LM358 / S8050 / TL431 |
| package | 封装 | SOT-23 |
| verified_by | 验证方式：ft-test / curve-trace / datasheet-confirm | ft-test |
| source_note | 来源批次/月份（脱敏，不含客户信息） | 2026-10 来料 |
| notes | 备注（如多义、限特定厂家） | 与 SC70 封装区分 |

红线：不做全量反查承诺；不含客户敏感信息；每条必须经合作方实测或手册确认，宁缺毋滥。首期建议 200-500 条覆盖合作方主营品类（电容标称/传感器家族/常用分立器件），够冷启动一个「合作方验证」标签。
