## NTC：一条故意做得陡峭的指数曲线

NTC 热敏电阻的温度特性是 R = R25·exp(B·(1/T − 1/T25))：温度升高电阻指数下降，25℃ 时 10kΩ 的探头（B=3950），85℃ 时只剩约 1.1kΩ。取对数后它变成 lnR 对 1/T 的直线——**B 值模型就是这条直线的两点式**：知道 25℃ 的阻值 R25 和斜率 B，整条曲线就定了。反解温度是初等变形：T = 1/(1/T25 + ln(R/R25)/B)。

便宜是有代价的：真实 NTC 的 lnR–1/T 关系不是严格直线，B 值模型在 20–100℃ 窗口内误差一般 ±1℃ 以内，出了窗口曲线弯曲、误差迅速放大。更隐蔽的是**口径坑**：B 值是用哪两个温度点定义的（B25/50、B25/85、B25/100）数值各不相同，规格书标 B=3950 是 25/85 口径，你拿去算 50℃ 就会系统性偏差——跨口径混用能把 85℃ 的阻值算错 20% 以上。拿到规格书第一件事是找 B 值的温度下标。

要宽温区精度就上 **Steinhart-Hart**：1/T = A + B·lnR + C·(lnR)³——在 B 值的线性项上加一个三次曲率项（没有二次项，这是原始论文的拟合形式）。三个系数用三个标定点解 3×3 线性方程组（高斯消元），标定点建议取测温范围的两端加中间。反方向（温度→阻值）没有解析解，用牛顿迭代解 A + B·x + C·x³ = 1/T（x=lnR），导数 B+3Cx²，迭代变量钳位在 [−30, 30] 保证不跑出收敛域。宽温区（−40~125℃ 全程）误差可以压到 ±0.05℃ 量级——上限取决于你标定点的准确度，数学只负责不再添乱。

配套的分压电路还有一个选值技巧：上拉电阻取 **R25**。分压灵敏度在 R_pull 等于 NTC 当前阻值时最大，取 R25 意味着 25℃ 采样电压恰好 Vref/2、ADC 码值居中，常用温区的量程利用率最高。

## PT100：贵金属的近线性，和负温区的四次项

铂电阻是另一个极端：材料稳定、近乎线性、可溯源到国际温标。IEC 60751 的 **Callendar-Van Dusen 方程**：t≥0 时 R(t) = R0(1 + At + Bt²)，就两个系数——A = 3.9083×10⁻³、B = −5.775×10⁻⁷，0→100℃ 平均灵敏度约 0.385Ω/℃（0℃ 处 0.391）。正温区是二次方程，阻值反解温度有**解析解**（求根公式直接算）；负温区补一项 C(t−100)t³ 变成四次方程，只能牛顿迭代反解（收敛阈 10⁻⁹），量程 −200~850℃。

PT100 和 PT1000 用同一种铂丝、同一组系数，差别只在 R0（100Ω 对 1000Ω）。真正的分野在**引线**：两线制接法下导线电阻直接串进读数，1Ω 导线电阻对 PT100 是 1÷0.385 ≈ **2.6℃ 的虚高**，对 PT1000 只有 0.26℃——阻值大十倍，引线误差小十倍。所以长导线、两线制、低成本场合优先 PT1000；配三线/四线制变送器的工业现场 PT100 探头生态更全。这是「传感器选型 = 传感器 + 引线 + 变送器一起选」的经典案例。

## 热电偶：塞贝克电压的非线性，与冷端这条生死线

K 型热电偶输出的是微伏级电压（约 41µV/℃），但「每℃ 41µV」只是粗略的一阶近似——真实曲线弯得厉害，NIST ITS-90 标准用**分段多项式**逼近：负温区（−200~0℃）十阶多项式，正温区（0~1372℃）九阶多项式**再加一个高斯指数项** a0·exp(a1(t−a2)²)（捕捉 1370℃ 附近的曲线异常），分段点 0℃ 处两段连续。反向（mV→温度）另有分段逆多项式，断点在 −5.891 / 0 / 20.644 / 54.806 mV。没有公式可推理，只有「标准系数 + 标准分段」照章执行——这正是它和 NTC/PT100 的气质差别：前两者是「模型简洁、参数标定」，热电偶是「查表思想的多项式化」。

比非线性更要命的是**冷端**：热电偶测的是热端与冷端的**温差电势**，表上所有 mV 值都以冷端 0℃ 为基准，而你的冷端其实躺在接线端子上随室温漂。补偿链条：E_total = E_实测 + E(冷端温度)——先测出冷端（接线盒）温度，把它对应的电势加回去，再用逆多项式反查热端温度。25℃ 冷端不补偿，K 型直接错约 1℃；更常见的翻车是**二次补偿**：MAX6675/MAX31855 这类解码芯片已在片内做了冷端补偿，软件层再补一次等于把同一误差加了两遍——用这类模块时冷端温度必须填 0。
