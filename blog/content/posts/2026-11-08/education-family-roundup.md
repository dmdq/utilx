家里两个娃，一个刚学进位借位天天出错，一个备战公考模考完想估分；自己还惦记着寒假出境游，护照够不够期限没查过。家里的事从来都是具体的活：学习要练、成绩要看、证件要盯，一样赶不上就得回头补。站点把这类工具攒到 11 件，按「打印练习件、学习辅助、成绩与规划」三组理一遍，缺什么补什么。

## 打印练习件：纸上的基本功

三位数进位加法十道错三道，{{< tool id="vertical-arithmetic-printer" >}}竖式计算器{{< /tool >}}生成一页竖式练习打印出来，每天十分钟当早课，错题当场订正。老师要求每周练英文书写，{{< tool id="english-copybook-generator" >}}英语字帖生成器{{< /tool >}}把本周单词排成字帖，描红临写随娃挑，顺手连单词也认了。认钟表总是五分五分地数，{{< tool id="clock-worksheet-generator" >}}认识时钟练习纸{{< /tool >}}画几页钟面题，当游戏闯关着学。超市找零算不利索，{{< tool id="rmb-money-worksheet" >}}人民币练习纸{{< /tool >}}印几张元角分换算题，边玩边把零钱概念建起来。

## 学习辅助：把习惯搭起来

行程问题见题就懵，{{< tool id="math-word-problem-generator" >}}应用题生成器{{< /tool >}}按年级和题型出一批专项题，哪个弱练哪个，不用再四处搜题。读完一本书转头就忘，{{< tool id="reading-log-tracker" >}}读书清单与阅读记录{{< /tool >}}把书目和一句感想记下来，一学期回看收获一目了然。兴致来了写了首七律想发圈，{{< tool id="tone-pattern-checker" >}}律诗平仄检查器{{< /tool >}}先过一遍平仄，格律毛病改完再发，不怕被懂行的挑出错。

## 成绩与规划：看得见的进度条

期中考完要给班里做成绩小结，{{< tool id="grade-statistics-analyzer" >}}成绩等级统计分析{{< /tool >}}平均分及格率分数段一键出报表，发家长群直接用。模考对完答案心里没底，{{< tool id="xingce-score-estimator" >}}行测估分器{{< /tool >}}按模块估出得分，弱项清清楚楚，最后一个月主攻方向就有了。学校办演讲赛七个评委打分，{{< tool id="contest-scoring-calculator" >}}演讲比赛计分器{{< /tool >}}去掉最高最低再求平均，现场报分不冷场。寒假计划出境游，{{< tool id="passport-expiry-checker" >}}护照有效期提醒{{< /tool >}}先查一眼有效期，不足六个月赶紧换新再订票，别卡在机场白跑。
