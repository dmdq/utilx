体检报告拿回家翻两页就塞进抽屉，减重计划永远停在「明天开始」，一天八杯水全靠记性——身体的事，难的不是懂道理，而是持续地记和看。站点里的健康追踪工具已经攒到 18 件，这篇分成三组：先记体征，再算吃进嘴里的，最后练起来、盯目标。所有数据在浏览器本地记录，不上传云端。

## 体征记录：给身体记台账

每天量完血压顺手录进{{< tool id="blood-pressure-tracker" >}}血压健康评估{{< /tool >}}，趋势图比记忆可靠得多。夜里翻来覆去睡不踏实，把入睡起床时间填进{{< tool id="sleep-quality-calculator" >}}睡眠质量计算器{{< /tool >}}，看看睡眠落在哪一档。体重之外更该量围度，{{< tool id="body-measurement-tracker" >}}身体围度追踪器{{< /tool >}}把胸围、腰围、腿围按周记下来，变化先从腰上显形。想知道体脂大概多少，用卡尺捏起皮褶，{{< tool id="caliper-calculator" >}}皮脂厚度计算器{{< /tool >}}估一个参考值。体型分布看比例，{{< tool id="waist-to-hip-calculator" >}}腰臀比计算器{{< /tool >}}拿腰围比臀围，苹果型梨型一算便知；再看一条更简单的线，{{< tool id="waist-to-height-calculator" >}}腰高比计算器{{< /tool >}}量量腰围有没有超过身高的一半。

## 饮食营养：吃进去的先算清楚

开始管住嘴之前先定数，{{< tool id="nutrition-calculator" >}}营养需求计算器{{< /tool >}}按身高体重和活动量算出每日所需。三餐吃多吃少记一笔，{{< tool id="calorie-counter" >}}卡路里计数器{{< /tool >}}让热量缺口不用心算；再细一点，蛋白、碳水、脂肪的配比交给{{< tool id="macro-tracker" >}}宏量营养素追踪器{{< /tool >}}逐日盯。目标热量定下来，{{< tool id="meal-planner" >}}一周食谱规划{{< /tool >}}摊到七天三餐，采购清单顺手就有了。水最容易被忘，{{< tool id="hydration-tracker" >}}饮水习惯追踪器{{< /tool >}}一杯一杯打卡，别等口渴才想起来。

## 训练与目标：练起来、看趋势

说清目标和每周能练几天，{{< tool id="workout-planner" >}}运动计划生成器{{< /tool >}}排一份可行的训练表，比照抄网红计划靠谱。练前练后别忽略柔韧性，{{< tool id="flexibility-assessment" >}}柔韧性评估测试{{< /tool >}}自测一下，硬拉不到位可能不是力量问题。增肌期盯体重会迷惑，{{< tool id="ffmi-calculator" >}}瘦体重指数计算器{{< /tool >}}扣掉脂肪看肌肉量，进步才看得见。想知道身体状态相当于几岁，{{< tool id="health-age-calculator" >}}健康年龄评估{{< /tool >}}按几项指标给个参考性的身体年龄，比实际年龄小就偷着乐吧。目标体重别死磕一个数字，{{< tool id="ideal-weight-calculator" >}}理想体重计算器{{< /tool >}}按身高给个合理区间；把区间变成日程，交给{{< tool id="weight-goal-planner" >}}体重目标规划器{{< /tool >}}拆成每周的小步子。最后是把一切串起来的{{< tool id="habit-tracker-health" >}}健康习惯追踪器{{< /tool >}}，早睡、忌糖、拉伸全放一张打卡表里，断一天也不许弃坑。

这些工具都是参考性质的助手，数值不构成医疗建议，指标异常请先找医生。记录本身就有价值——台账记满三个月，趋势比任何单次数值都说明问题。想把这些工具和运动计算、体测类一起用，可以逛逛[健康运动桌面](/collections/fitness-health-desk/)专题。
