文件出问题的姿势总是很固定：来路不明的压缩包不敢点、客户名单挤在一列里、要交的文档格式不对、硬盘里躺着三个一模一样的大文件。这类问题的解法都不复杂，难的是手边一时没有趁手的工具。这篇把 13 件文件处理工具按四组归位，遇到哪类问题就翻到哪一组。

## 查看与解包：先看清楚再动手

来路不明的压缩包，{{< tool id="zip-viewer" >}}ZIP压缩包查看器{{< /tool >}}不解压先列清单，看清里面装了什么再决定解到哪。部署 HTTPS 前核对证书，{{< tool id="pem-parser" >}}PEM证书解析器{{< /tool >}}读出域名、签发机构和有效期，到期前续签不用临时救火。本地开发用 .env、容器编排要 JSON，{{< tool id="env-json-converter" >}}.env与JSON转换器{{< /tool >}}两种格式互转，变量一份维护两边，迁移环境少抄一遍。

## 表格与数据：名单与规格的整理

多语言文案或两份环境配置要合成一份，{{< tool id="json-merger" >}}JSON合并工具{{< /tool >}}按规则合并并标出冲突项，翻译文件补词条时最省事。地址电话挤在同一列，{{< tool id="excel-column-splitter" >}}Excel地址姓名拆列{{< /tool >}}把姓名、省市区、手机号拆成独立列，几百行一次拆完，导出就能用。电商上架要列全规格，{{< tool id="sku-combination-generator" >}}SKU规格组合生成{{< /tool >}}把颜色乘尺码乘款式的组合全部列出，一条不漏，组合表直接贴进后台。

## 文档与转换：交付前的最后一道

把付费专栏攒成一本能翻的书，{{< tool id="epub-maker" >}}EPUB电子书制作{{< /tool >}}按章节生成 EPUB，阅读器里排版舒服。客户名单要进手机通讯录，{{< tool id="vcard-converter" >}}vCard联系人转换{{< /tool >}}把表格转成 vCard 批量导入，省去逐个手输。交接要留文字稿，{{< tool id="pptx-to-text" >}}PPT转文本{{< /tool >}}把几十页幻灯片的文字抽出来归档，会议记录有了底稿。需求评审要交 Word 版，{{< tool id="markdown-to-word" >}}Markdown转Word{{< /tool >}}把 .md 转成 .docx，标题列表样式基本不带丢。

## 安全与清理：收尾的三件

日志是 .gz 后缀打不开，{{< tool id="gzip-tool" >}}gzip压缩解压{{< /tool >}}就地解包直接看内容，服务器日志下载下来就能开。密码或密钥要发给同事，{{< tool id="text-encryptor" >}}文本加密解密{{< /tool >}}先加密成密文再走聊天工具，落到记录里也不怕，对方解开即用。素材库越攒越满，{{< tool id="duplicate-file-finder" >}}重复文件查找{{< /tool >}}按内容比对找重复，改过文件名的也认得出，删掉冗余释放空间。

13 件遵循同一个规矩：文件留在本机处理，不上传服务器。文件类的工具不怕多，怕的是用时想不起来有它——收藏一个入口比记工具名靠谱。识别类型、转换编码这些前置动作也在[文件处理流水线](/collections/file-ops-pipeline/)专题里，连同这篇的一起，文件的事基本不用离开浏览器。
