## SVG 导出：矢量图的"最后一公里"

图标和 Logo 的源文件几乎都是 SVG，但实际要用的地方——PPT、公众号封面、App 图标——全都要 PNG，而且经常要 1x/2x/3x 一套。{{< tool id="svg-to-png" >}}SVG转PNG{{< /tool >}}粘贴源码或拖入文件，勾选多个尺寸一次导出打包：矢量图按倍率栅格化，边缘永远锐利，不存在"放大会糊"的问题。工具会先做一层净化（去掉 SVG 里可能藏的脚本和事件属性）再渲染，透明背景默认保留，需要白底可以一键切换。

## GIF 拆帧：表情包的二创原料

看到一个好玩的 GIF 想改其中一帧，第一道坎是把它拆开。{{< tool id="gif-frame-extractor" >}}GIF抽帧{{< /tool >}}用自写的解码器逐帧解析：每一帧的延时、尺寸列出来，单帧下载 PNG 或全部打包。顺带能看到这个 GIF 到底几帧、循环参数是什么——做二创表情包或者分析动画节奏都用得上。

## 白边自动裁：电商主图的体面

供应商给的图四周带一圈白边，放详情页里显得特别"库存图"。{{< tool id="image-autocrop" >}}图片白边裁切{{< /tool >}}从四角取样确定背景色，容差可调（有点渐变的白也能容住），自动找出内容边界裁掉白边；透明底的图按透明边判定。支持批量，一次拖一文件夹主图进去，裁完打包下载。

## DPI：印刷稿的隐形参数

图在网上看没事，一到印刷就糊，多半是 DPI 的问题——屏幕按像素显示，印刷机按"每英寸多少点"取像素。{{< tool id="image-dpi" >}}图片DPI修改{{< /tool >}}直接改 PNG/JPEG 文件里的 DPI 元数据字节（PNG 的 pHYs 块、JPEG 的 JFIF 密度字段），不重新编码，画质一个比特都不动。页面上还有像素和厘米/英寸的互查换算，A4 三百 DPI 要多少像素这种数，填一下就出。

四件都归进图像分类，配合已有的 {{< tool id="image-resize" >}}图片尺寸调整{{< /tool >}}和 {{< tool id="image-compress" >}}图片压缩{{< /tool >}}，从格式、尺寸到印刷参数的处理链就齐了。
