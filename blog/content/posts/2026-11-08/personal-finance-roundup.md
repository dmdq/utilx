年底盘账，钱的事一件接一件：养老金账户又存了一年想知道滚到多少，朋友发来的众筹方案要核回本周期，自己接的私活报价还是拍脑袋定的，房贷车贷信用卡三笔债也不知道先还哪笔。站点的个人财务工具攒到 14 件，这篇按「投资与收益、接活与自由职业、账务日常」三组理一遍，遇到什么算什么。

## 投资与收益：先把回报算明白

朋友的小店发起众筹，许诺每年分红，{{< tool id="crowdfunding-roi-calculator" >}}众筹回报计算器{{< /tool >}}把投入和预期回报摊成年化，值不值得入当场有数。收了套老破小想看租金划不划算，{{< tool id="rental-yield-calculator" >}}房租收益计算器{{< /tool >}}按年租金和总价扣掉空置，回报率是二还是四一目了然。孩子还有十年上大学，{{< tool id="education-savings-calculator" >}}教育储蓄计算器{{< /tool >}}按目标学费倒推每月存多少，存钱计划不再凭感觉。个人养老金账户顶格存了三年，{{< tool id="pension-calculator" >}}个人养老金计算器{{< /tool >}}把缴存节奏和退休领取一次算清，缺口多大心里有底。半年折腾了十几笔调仓，{{< tool id="stock-profit-calculator" >}}股票收益计算器{{< /tool >}}把买卖价格和费用填进去，净赚净亏一目了然。

## 接活与自由职业：报价和提成别拍脑袋

从公司出来单干，不知道按什么价接活，{{< tool id="freelance-rate-calculator" >}}自由职业报价换算器{{< /tool >}}把月薪拆成日薪时薪，报出去有依据。手上两个 offer，一个现金高一个有期权，{{< tool id="offer-comparator" >}}Offer多维对比器{{< /tool >}}把薪资城市成长性摆到一张表里称重。月底对提成，底薪加阶梯比例混在一起，{{< tool id="commission-calculator" >}}销售提成计算器{{< /tool >}}按规则算出应得，和工资条对一遍。大促满减叠券再凑单，到底省了多少，{{< tool id="promotion-price-calculator" >}}大促到手价计算器{{< /tool >}}直接给到手价，真便宜还是凑单坑一算便知。

## 账务日常：把日子里的账排顺

团建八个人垫了三笔钱，{{< tool id="bill-split-calculator" >}}AA分账计算器{{< /tool >}}算出谁该转谁多少，群里发一下就清账。换汇前看到两家银行牌价有差，{{< tool id="forex-arbitrage-calculator" >}}外汇套利计算器{{< /tool >}}把价差折成收益做个参考，够不够折腾手续费先看清。三笔债利息高低不一，{{< tool id="debt-payoff-planner" >}}债务还款计划器{{< /tool >}}排出先还哪笔的顺序，省下的利息看得见。跳槽谈了个税前价，到手多少没概念，{{< tool id="salary-reverse-calculator" >}}税前税后互推计算器{{< /tool >}}社保公积金个税一路扣完再反推，谈薪不糊涂。小店经营一年想做个体检，{{< tool id="business-finance-analyzer" >}}企业财务分析器{{< /tool >}}把毛利率和负债水平摆出来，家底健康不健康一眼看穿。

14 件计算器全部在浏览器本地运行，输入不出门，打开就能用。算清眼前这笔只是第一步，房贷、记账、保单这些更大的家庭账，可以接着逛[家庭财务套装](/collections/family-finance-suite/)专题，家用财务一次配齐。
