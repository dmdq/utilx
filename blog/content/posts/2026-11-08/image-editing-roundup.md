日常修图多半是小活：截图加两行说明、给照片打个码、把长图切开发朋友圈、给素材换个背景。为这些事开专业软件太重，站点的图片编辑工具攒到了 25 件，这篇按四组理一遍，全部在浏览器本地处理，图不会传到任何服务器。

## 加字与合成：往图上放东西

给照片和素材批量打版权标，用{{< tool id="image-watermark" >}}图片水印{{< /tool >}}设好位置和透明度一次铺完。截图要加说明文字，{{< tool id="image-text" >}}图片添加文字{{< /tool >}}支持多行多样式，比手机相册的标注工具能打。想做聊天记录式的搞笑图，{{< tool id="image-meme" >}}表情包制作器{{< /tool >}}白底黑字几秒出图。往产品图上叠 logo 或者做半透明叠加效果，{{< tool id="image-overlay" >}}图片叠加工具{{< /tool >}}调好图层透明度就行。几张照片想拼成一张发群里，{{< tool id="image-collage" >}}拼图制作器{{< /tool >}}挑个模板拖进去；规则的多图合并成长图则用{{< tool id="image-merge" >}}图片合并{{< /tool >}}，纵向横向都能接。修完图想跟原图对比，{{< tool id="image-compare" >}}图片对比工具{{< /tool >}}左右滑动看差异，发动态演示也直观。

## 调整与变换：让照片换个样子

拍歪的照片用{{< tool id="image-rotate" >}}图片旋转翻转{{< /tool >}}掰正，镜像翻转也在里面。想让照片有点氛围感，{{< tool id="image-filter" >}}图片滤镜效果{{< /tool >}}提供胶片、黑白、复古等预设一键套用。证件照和头像要加白边或圆角，{{< tool id="image-border" >}}图片边框圆角{{< /tool >}}顺手处理。背景太乱想换掉，{{< tool id="image-background" >}}图片背景处理{{< /tool >}}换色换图都行。海报和头像做双色调风格，交给{{< tool id="image-duotone" >}}双色调效果工具{{< /tool >}}，两种颜色就能出高级感。截图里有敏感信息，{{< tool id="pixelate" >}}像素化工具{{< /tool >}}把选中区域打成马赛克，比涂黑好看。

## 裁切与拆分：把一张图变成好几张

扫描件四周全是白边，{{< tool id="image-autocrop" >}}图片白边裁切{{< /tool >}}自动识别边缘裁干净。要把一张图切成均匀网格发组图，{{< tool id="image-split" >}}图片分割{{< /tool >}}按行列切开。超长聊天记录截图放不进朋友圈，{{< tool id="long-image-splitter" >}}朋友圈长图分割{{< /tool >}}按高度切段并做好衔接。发九宫格动态用{{< tool id="image-grid-splitter" >}}九宫格切图{{< /tool >}}，切完按顺序上传就行。

## 格式与细节：收尾的那几步

几张图想合成动图，{{< tool id="gif-maker" >}}GIF制作工具{{< /tool >}}调好帧率和循环就导出；反过来拿到别人的动图想抽素材，{{< tool id="gif-frame-extractor" >}}GIF抽帧{{< /tool >}}把每一帧拆成图片。图标要位图格式，{{< tool id="svg-to-png" >}}SVG转PNG{{< /tool >}}按倍数高清导出。印刷前发现分辨率不对，{{< tool id="image-dpi" >}}图片DPI修改{{< /tool >}}调整 DPI 元信息。想弄清一张图的尺寸、大小、格式，{{< tool id="image-info" >}}图片信息查看{{< /tool >}}一览无余。给照片加节日边框，{{< tool id="image-frame" >}}相框效果工具{{< /tool >}}挑个样式套上。公众号头图想看在封面墙里的效果，{{< tool id="cover-grid-preview" >}}封面瀑布流预览{{< /tool >}}先模拟一遍再发布。新买的手机要壁纸，{{< tool id="wallpaper-adapter" >}}壁纸多机型适配{{< /tool >}}按各机型分辨率一次裁好。
