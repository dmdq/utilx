车间里的翻车很少是大错误，多是「差不多」：扭矩差不多、皮带差不多、电流差不多，最后设备差不多就坏了。这些参数在图纸上都有公式，车间里缺的只是把公式变成顺手可查的工具。这一篇把站里的 13 件机电速算器按三条线清点一遍，每件一句话说清用在哪，维修与工艺师傅照单取用。

## 紧固与传动

连接与传动的参数都有表可查，别再凭手感：扭矩差半格法兰就渗油，皮带短一截轴承就提前报废。{{< tool id="bolt-torque-table" >}}螺栓拧紧扭矩对照{{< /tool >}}按强度等级与螺纹规格给扭矩值，法兰螺栓要均匀受力就靠它；{{< tool id="spring-rate" >}}弹簧刚度计算{{< /tool >}}算线径、圈数对应的弹簧常数，选缓冲与复位弹簧先过这一步；{{< tool id="chain-sprocket" >}}链条长度计算{{< /tool >}}按中心距与齿数算链节数，链条传动定制下单前先出这个数；{{< tool id="belt-length-calculator" >}}皮带长度计算器{{< /tool >}}算开口与交叉皮带的基准长度，选型不跑第二趟五金店；{{< tool id="gear-ratio-reducer" >}}减速比计算{{< /tool >}}在速比、扭矩与转速之间换算，选减速机配电机都用得上。

## 流体与执行

气缸液压的力从公式来，不从感觉来：缸径定面积，面积乘压力才是真正能出的力。{{< tool id="pneumatic-cylinder" >}}气缸推力计算{{< /tool >}}按缸径与气压算推拉力，夹具顶不紧、推不动先回来核这一步；{{< tool id="hydraulic-force" >}}液压压力计算{{< /tool >}}在系统压力、缸径与输出力之间互算，油缸选型与泵站匹配都用它；{{< tool id="viscosity-converter" >}}粘度换算器{{< /tool >}}在运动粘度、动力粘度与恩氏粘度之间互转，换液压油或采购润滑油时对得上说明书。

## 加工工艺

工艺参数算对一遍，废品就少一批，折弯、电镀、焊接三道工序的坑各有各的算法。{{< tool id="sheet-metal-bend-calculator" >}}钣金展开计算器{{< /tool >}}按折弯系数算展开料长，下料不再多切一块板；{{< tool id="electroplating-time-calculator" >}}电镀时间计算器{{< /tool >}}按电流密度与目标镀层厚度算时长，排产与报价都有依据；{{< tool id="weld-strength-calculator" >}}焊缝强度计算器{{< /tool >}}按焊脚尺寸与长度估算焊缝承载，焊接结构受力校核用；{{< tool id="welding-amperage-calculator" >}}焊接电流选择器{{< /tool >}}按板厚与焊条直径给电流区间，新手不再烧穿薄板；{{< tool id="stepper-pulse-calculator" >}}步进电机计算器{{< /tool >}}算脉冲当量、转速与扭矩的对应关系，调数控和 3D 打印机都离不开。
