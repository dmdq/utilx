## 会开得长，是因为没写下来

周一例会开到第九十分钟还没散，散会时每人领走的口头任务各有各的版本——这种会的问题不是人多，是议程没立住。再往链条后头走，毛病一个个冒出来：季度启动会上 SWOT 四个格子填得满满当当，散会就归档；OKR 写出来像标语；项目出了事才想起没人记过风险。这批上新六件工具：{{< tool id="meeting-agenda-generator" >}}会议议程生成器{{< /tool >}}、{{< tool id="swot-analysis-generator" >}}SWOT分析生成器{{< /tool >}}、{{< tool id="decision-framework-cards" >}}决策执行框架卡{{< /tool >}}、{{< tool id="okr-generator" >}}OKR生成器{{< /tool >}}、{{< tool id="retro-templates" >}}团队复盘模板{{< /tool >}}和 {{< tool id="risk-register-generator" >}}项目风险登记表{{< /tool >}}，会前、会中、会后各就各位。

## 议程先立时间盒，盘点后必须交叉

会前最重要的一件事，是把每个议题装进时间盒。{{< tool id="meeting-agenda-generator" >}}会议议程生成器{{< /tool >}}逐条议题设时长，自动汇总总时长——加出来超了两个钟头，就在会前砍议题，而不是会中超时硬撑；每条议题标好会前材料和责任人，开会时到了时间盒上限自动告警，要么当场拍板，要么挂起另约，不让一个话题把整场会吃掉。

季度盘点离不开 SWOT，但最常见的浪费是填完四格就散会。优势、劣势、机会、威胁只是盘点，两两交叉成 TOWS 才是开方：SO 用优势去抓机会，WO 补短板去接机会，ST 靠优势躲威胁，WT 收缩规避。{{< tool id="swot-analysis-generator" >}}SWOT分析生成器{{< /tool >}}在四象限填完后自动给出交叉策略建议，导出 SVG 或打印贴墙。只做 SWOT 不做交叉，等于只体检不开方，[SWOT 与 TOWS 矩阵词条](/wiki/swot-tows/)把这层关系讲透了。

## 三张框架卡，各管一段

决策最容易犯的错是拿一套框架套所有问题。{{< tool id="decision-framework-cards" >}}决策执行框架卡{{< /tool >}}备了三套，分场景用：立项追问用 5W2H——为什么做、谁负责、什么时候、花多少钱，一个问题答不上来就说明还没想清；改进闭环用 PDCA——计划、执行、检查、处理，四步走完才叫改过一件事；排优先级用艾森豪威尔四象限——重要紧急的立刻做，重要不紧急的排进日程，别让"救火"把"防火"挤没了。三张卡填完都导出成行动清单，会后跟着人走。

## OKR 两个校验：有度量，有权重

OKR 写废大多坏在两处。第一处是 KR 没有度量，"显著提升用户体验"这种句子，{{< tool id="okr-generator" >}}OKR生成器{{< /tool >}}的校验直接过不去——换成"NPS 从 30 提到 45"才行。第二处是权重乱给，五个 KR 各标 50%，加起来 250%，谁也说不清哪个更重要，工具强制权重归一化到 100%。写完还有一道对齐检查：KR 往上要对得齐目标，横向要对得齐协作部门的口径，导出前过一遍，免得季度末才发现两条线各跑各的。打分口径也一并标好：季度末拿到 0.7 是理想达成，0.3 以下说明这条 KR 定飘了，1.0 反而提示目标定保守了。每个 KR 还要标信心值——开季时只有五成把握的 KR 和十成把握的 KR，做成了含金量也不一样。

## 复盘聚焦，风险兜底

项目收尾的复盘最容易开成吐槽会。{{< tool id="retro-templates" >}}团队复盘模板{{< /tool >}}备了三套框架：KISS（保持、改进、开始、停止）适合节奏快的迭代，4Ls（喜欢、学到、欠缺、渴望）适合氛围松的团队，Start-Stop-Continue 最直白，适合头一回做复盘的组。条目写到二三十条时靠投票聚焦——全员投出前三，行动项汇总导出，落到人头和日期上，落不到人头上的复盘等于没复。

风险这页账要记在出事之前。{{< tool id="risk-register-generator" >}}项目风险登记表{{< /tool >}}按可能性×影响的 5×5 矩阵自动定级：得分 15 及以上算高，8 到 12 算中，6 及以下算低——口径的细节在边界上：4×2=8 分归中不归高，别把黄色风险报成红色吓自己，也别把 12 分的当成绿色放过去。缓解措施逐条跟踪，登记表导出打印，评审会上人手一页。风险矩阵的定级逻辑和常见误区，[风险矩阵（P×I）词条](/wiki/risk-matrix/)里写全了。

这六件连同述职、周报类工具一起收在[职场文书工具箱](/collections/workplace-writing-kit/)专题里。会议之外的另一条沟通线是 1on1：{{< tool id="one-on-one-agenda" >}}1on1 沟通议程{{< /tool >}}内置进度、成长、障碍、职业发展四区话题库，按 30 分钟时间盒生成提纲，谈完的行动项没完成，下次开场自动列在"上次遗留"里——一对一最容易死在"聊完就忘"，它把闭环补上了。
