## 速查表的通病：只能看，不能练

考前一周，学生党的浏览器里总会躺着五六张标签页：不规则动词表、时态汇总表、音标表。这类速查表有个共同的毛病——只能看，不能练。盯着表看的时候觉得全都认识，合上屏幕默写，came 和 comed 打架、过去分词丢三落四。问题不在记性，而在"认出来"和"想得起"是两种强度差别很大的记忆：前者靠看，后者只能靠测。这批上新把四张常备速查表都做成了能查也能测的形态：{{< tool id="irregular-verbs-table" >}}不规则动词速查{{< /tool >}}、{{< tool id="english-tense-reference" >}}英语时态速查{{< /tool >}}、{{< tool id="phonetic-chart" >}}英语48音标表{{< /tool >}}和 {{< tool id="math-symbol-reference" >}}数学符号速查{{< /tool >}}，末了配一件 {{< tool id="reading-speed-test" >}}阅读速度测试{{< /tool >}}——连"读得快不快"也给你一个带口径的数。

## 不规则动词：先分组，再蒙列

约 180 个不规则动词一股脑从头背到尾是最笨的办法。{{< tool id="irregular-verbs-table" >}}不规则动词速查{{< /tool >}}按变化形态分了组：AAA 三式同形（cut-cut-cut、put-put-put），ABB 后两式同形（buy-bought-bought），ABA 一三同形（come-came-come），ABC 三式各异（begin-began-begun）。分组的价值在规律肉眼可见：ABC 组里藏着一串 i-a-u 的元音变位——begin、drink、sing、swim、ring 全是这个路数，记住一组等于记住五六个。查只是保底，默写模式把原形、过去式、过去分词任意一列蒙住让你填，随机测验再从全表抽词打乱着考——背没背下来，测一遍就知道。表本身支持搜索和打印，贴在书桌前当挂图也行。

## 十六个时态：先挂时间轴，再背公式

时态难不在公式多，在于脑子里没有时间轴。16 个时态是 4 个时间（现在、过去、将来、过去将来）乘 4 个体（一般、进行、完成、完成进行）的完整矩阵。{{< tool id="english-tense-reference" >}}英语时态速查{{< /tool >}}把这个 4×4 矩阵整张摆开，每格给出公式结构和例句，主动被动两套对照，还能按时间和体筛选。时间轴可视化是它和纸面表格最大的差别：完成时的锚点画在"过去某个点、影响延续到现在"，过去将来时挂在"过去某个节点往后看"——will do 和 would do 的区别不用背口诀，看轴就懂。矩阵还有个隐藏用法：哪一格你从没主动用过，写作文时就该绕着那一格多练几句。

## 四十八个音标：清浊成对记

48 个国际音标单列着背既枯燥又容易混。{{< tool id="phonetic-chart" >}}英语48音标表{{< /tool >}}按单元音、双元音和辅音分栏，辅音里清浊成对排布：p 对 b、t 对 d、s 对 z、ʃ 对 ʒ——每一对的口型舌位完全相同，区别只在声带动不动。成对记的好处是发音要点可以共享，练会一个等于练会两个。每个音标配了例词、发音要点和口型说明，易混音对比专治顽疾：ship 和 sheep 差在 /ɪ/ 短促还是 /iː/ 拉长，think 和 sink 差在舌尖有没有伸到上下齿之间——这些差别光看文字体会不到，对照着逐个听、按口型说明模仿才是正路。

## 符号查得到，阅读测得出

{{< tool id="math-symbol-reference" >}}数学符号速查{{< /tool >}}按集合、关系、运算、逻辑、希腊字母分类检索，每个符号给四样东西：Unicode 写法（日常打字直接用）、LaTeX 写法（写论文排版用）、读法和含义示例。∑、∫、≤、∈、∀ 这些符号手打打不出来、LaTeX 又背不熟，工具把"回忆怎么输入"变成"复制粘贴"，一键复制按的就是这个场景。

查完符号再看读文章这件事。{{< tool id="reading-speed-test" >}}阅读速度测试{{< /tool >}}的用法是粘贴一段文章、计时默读、读完自评理解度，核心口径是**速度×理解度=有效速度**——只报每分钟多少字不谈理解度没有意义，扫过一遍什么都记不住的 600 字，不如读懂九成的 400 字。参考区间也有：成人默读中文大约 300-500 字/分钟，精读 200-300，快速略读能到 600-800。测出来的数落在哪一档、怎么练，[阅读速度（WPM）词条](/wiki/wpm-reading-speed/)里把口径写全了；想再加一层输出训练，之前上线的[英语听写挖空生成](/tools/dictation-generator/)和这套"能练"的速查表是一条路子。最后给诗词爱好者一个彩蛋：{{< tool id="tone-pattern-checker" >}}律诗平仄检查器{{< /tool >}}把五绝到七律的 16 种标准格式谱录成了交互对照——粘贴诗句逐字标平仄，普通话读平但中古是入声的字（白、竹、月这类）会黄标提醒，还顺带查孤平和三平尾。写旧体诗最怕"看着顺口其实拗了"，它比肉眼可靠。
