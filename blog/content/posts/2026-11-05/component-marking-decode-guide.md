## 板子越老，认件越费劲

维修老设备的顺序通常是：先看症状，再拆板找嫌疑人。可旧板子上的元件个个"素面朝天"——十年前的激光丝印淡得像铅笔印，色环电感的颜色褪得分不清棕和红，SOT-23 封装上就两三个字符的缩写还查无此号。认不出件，后面的测量都无从谈起。

这批上新把解码线补齐了：{{< tool id="ic-marking-decoder" >}}IC丝印解读器{{< /tool >}}专管芯片丝印里的批次信息，配上已有的{{< tool id="capacitor-code-reader" >}}电容标号读取器{{< /tool >}}、{{< tool id="resistor-color-code" >}}电阻色环计算器{{< /tool >}}和{{< tool id="inductor-code-reader" >}}电感标号读取器{{< /tool >}}，四件解码器并排开着，一块旧板子从电阻到芯片基本都能报出型号口径。

## date code：一颗芯片的"出生日期"

芯片丝印从左到右常见是：厂商前缀、型号缩写、**date code**、批号。date code 主流格式 YYWW——「2547」就是 2025 年第 47 周（11 月 17-23 日）。「2401」是 2024 年第 1 周；也有 YYMMDD 和年+天的变体，解读器会同时给出几种可能的读法并标明哪种格式合法。

date code 在维修和采购各有一用。维修侧，同型号不同批次的元件可能有硅改版差异（比如老批次功放块的偏置点不同），按批次换件能少走弯路。采购侧，date code 是判断**库存时间**的第一线索：一颗"全新原装"的料印着 2503，仓库里躺了一年半的库存料，价格和质保都该重新谈。

前缀部分，解读器内置了三十多条常见厂商线索：LM 源自 National Semiconductor（现属 TI）、MC 源自 Motorola（现 onsemi）、TA 是东芝、NJM 是 JRC……页面上有显著的免责说明：**厂商并购频繁、多厂共用前缀，前缀仅供线索，反查具体型号请用专业数据库**。这工具管的是"看懂丝印"，不是替你查型号——这个边界我们守得很清楚。

## 色环与标号：三件套各管一摊

贴片元件的标号自成体系。{{< tool id="capacitor-code-reader" >}}电容标号读取器{{< /tool >}}管 104 这类三位码（10×10⁴ pF = 100nF）。{{< tool id="inductor-code-reader" >}}电感标号读取器{{< /tool >}}管两类：色环电感四环读法——棕黑金金是 1.0µH ±5%，褪色严重的环靠"误差环在末尾、乘数环在中间"的顺序规律反推；贴片电感三位码——101 = 100µH，带 R 的小数记法 4R7 = 4.7µH、R47 = 0.47µH。{{< tool id="resistor-color-code" >}}电阻色环计算器{{< /tool >}}管色环电阻双向核对。

## date code 之外：翻新件的五点交叉验证

丝印能看懂了，翻新件还得靠交叉验证，这五点比单看丝印可靠：

**丝印质感**——原厂激光打标字底平、色深均匀；重打标往往字深偏浅、有两次打标的重影。**引脚光洁度**——库存新料引脚光亮，拆机翻新件引脚有焊锡残留的半月形。**封装光泽**——翻新件常重新喷砂，光泽发乌。**date code 与逻辑矛盾**——批次比整机上市日期还早的"全新料"，本身就是红牌。**价格与渠道**——低于现货市场价太多的"原装"，概率上不可能是原装。

批次质量的另一半在测试数据里：来料抽检的 DPPM 记录、按批次的良率走势，和丝印批次一起看才是完整的画像——这部分在[IC 测试质量台](/collections/ic-test-quality/)专题里有工具承接。想系统了解丝印结构的，[芯片丝印与 Date Code 词条](/wiki/ic-date-code/)把四段结构和翻新识别写全了。
