## 配平是一道矩阵题

中学配平靠观察法：盯着 Fe、S、O 各自配到两边相等。把这件事写成数学，是标准的线性代数：设每种物质一个未知系数 x₁…xₙ，每种元素列一条守恒等式——左边的原子数等于右边。把生成物系数移项（取负号），就得到一个齐次线性方程组 **A·x = 0**：A 的行是元素，列是物种，格子是「该元素在该化学式里的原子个数，反应物为正、生成物为负」。

以 Fe₂(SO₄)₃ 相关反应为例，矩阵每列如 `Fe: 2, S: 3, O: 12`，配上符号。配平就是找 A 的**零空间**——让所有守恒式同时为零的系数向量。零空间天然非平凡（方程右端是零，齐次系统永远有零解），配平者要的是其中的**正整数向量**，再约到最简比。

## 解析先行：递归下降与大小写玄机

进矩阵之前得先把 `K4[Fe(CN)6]` 数成 `{K:4, Fe:1, C:6, N:6}`。解析器走递归下降：化学式 = 一串「元素符号 + 可选个数 | 括号分组 + 可选倍数」，括号分组里再递归同样的规则，`() 与 [] 语义相同但必须各自配对`，右括号后的数字乘进组内每一项。

大小写是新手解析器最容易翻车的地方：`Co` 是钴元素，`CO` 是碳加氧——大写字母开新元素、紧随的小写字母属于它，一个字符的差别改变整行的元素集合。解析失败的报错精确到字符位置（第几个字符出了什么问题），比一句「格式错误」有用得多。这套解析器是全站共用的底座：{{< tool id="chem-equation-balancer" >}}化学方程式配平{{< /tool >}}与 {{< tool id="molar-mass-calculator" >}}摩尔质量计算器{{< /tool >}}数的是同一棵语法树。

## 有理数消元：浮点凭什么翻车

解零空间走高斯消元化行阶梯形。为什么不直接用浮点数？配平系数是精确的小整数比，而消元过程要做大量除法——浮点除法的舍入误差经过几轮消去会被放大，本该是 `1/3` 的位置算出 `0.33333333`，回代出的系数带着毛刺，通分成整数时对不上（×3 得到 0.9999…，取整就错）。解化学配平这种「答案必须是精确整数」的问题，浮点是错误的工具。

正解是手写有理数运算：每个数存成分子/分母，加减乘除全用整数运算——加法通分（lcm）、乘法约分（gcd），全程零误差。性能代价在现代设备上可以忽略：矩阵通常就几行几列，几千次整数运算眨眼完成。

```text
RREF 化简 → 主元列与自由列
  自由列 = 0   → 只有零解，无法配平
  自由列 > 1   → 零空间维数 ≥2，多组配平（如实搜多解场景）
  自由列 = 1   → 唯一方向：自由变量取 1，主元变量 = 该行自由列系数的相反数
```

## 从零空间方向到最小整数比

唯一自由变量取 1、回代主元变量后，解向量是一串有理数。最后一步是「变身整数」：对所有分母取最小公倍数 L，每个分量乘 L 化整；再对整数向量取最大公约数 G 整体约分——得到的即**最小正整数比**。若约分后出现负系数（零空间方向指向了「反应物变生成物」的另一侧），说明该方向不是合法配平，返回无法配平。这一步的诚实输出很关键：有的反应在整数域无解（如某些看似合理实则不可配平的式子），工具应当明说，而不是硬吐一组错数。

配平结果的最后一道工序是**守恒核对表**：按元素逐行核对左个=右个，全绿才交卷——用独立验证兜住求解链路的任何意外，这比配平本身更接近「工程」的部分。
