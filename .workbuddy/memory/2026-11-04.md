## 架构评估：是否需要迁 Next.js / Astro
结论：**保持 Nuxt 4，不迁移**。项目是 Nuxt 4.6 + SSG(`nuxt generate`) + Tauri 2 桌面壳 + PWA，规模 746 工具页路由 / 748 注册项 / 818 个 .vue。

- 运行时其实已优化：Nuxt 按路由 code-split；重型库(pdfjs / xlsx / jszip / spine / lamejs / heic2any 等)在工具页内 `await import()` 按需加载；Sidebar 是数据驱动(只 import `~/data/categories`)，不 eager 引入工具组件。单工具页不会因工具总数变多而变慢。
- 用户感知"慢"的真实来源：① **构建期 generate 随工具数线性增长**(配置里已有 OOM 缓解：concurrency 2、payloadExtraction、manualChunks、esbuild)；② 聚合页(`/all`、首页)渲染 700+ 卡片需虚拟列表。
- Next.js 是平替(Vue→React 重写 800+ 组件)，Astro 擅长内容站而博客已由 Hugo 承担 —— 两者都不解决上述瓶颈。
- 商业化(登录注册/充值/联网工具)需**新增独立云后端**，与前端框架正交；Tauri 桌面端同样要调云 API。
- 后续性能路线：聚合页虚拟列表、热门页预渲染 + 长尾 ISR、generate 移到 CI 并行。

## 分页改为真实路径 `/all/page/N`（提交 `29368f45`）
- **背景**：用户静态部署到 nginx，明确要求分页是 `/all/page/2`，不能是 `/all?page=2`。原 query 分页（`339a8ef8` 引入）在 SSG 下只有一份 `/all/index.html`，第 2..16 页内容不存在于静态 HTML，分页按钮又是 `<button>`+JS，爬虫发现不了；`?page=` 还会被 canonical 折叠。
- **结构**：`src/pages/all.vue` 拆成 `src/components/AllToolsDirectory.vue`（共享目录主体）+ `src/pages/all/index.vue`（第 1 页壳）+ `src/pages/all/page/[page].vue`（2..16 页壳，`definePageMeta.validate` 限制范围）。页码由 `route.params.page` 决定，SSR 直接输出对应页内容。
- **配置**：新增 `src/data/pagination.js`（`TOOLS_PAGE_SIZE=48`、`TOTAL_TOOL_PAGES=16`、`toolPagePath()`）；`nuxt.config.ts` 按总页数自动生成 `/all/page/2..16` 加进 `nitro.prerender.routes`；sitemap 脚本补 15 条分页（priority 0.4）。
- **SEO**：每页独立 title/description、自引用 canonical（生产 `https://www.util.cn/all/page/N`）、prev/next；筛选/搜索仍是 query，客户端挂载后应用，筛选态加 `noindex, follow`，静态 HTML 无 noindex。分页链接改用 `NuxtLink` 输出真实 `<a href>`。
- **实测**：`npm run generate` 1h39m、2607 routes；15 个 `all/page/N/index.html` 全部生成（约 178KB/页，第 16 页 165KB）；每页卡数 48/48/42；`/all/page/16` 无 next；`/all/page/1` 不生成；`/all/page/99` 404。PWA precache manifest 里正好是 `all/page/N`（15 条，无 `index.html` 后缀），请求无尾斜杠也能命中，不会被 `navigateFallback: '/'` 兜到首页。
- **nginx 要点**：`location / { try_files $uri $uri/index.html $uri/ =404; }`。若用常见 `try_files $uri $uri/ /index.html`，`/all/page/2` 会 301 到 `/all/page/2/`，且未生成页码会软 404 成首页。canonical 无尾斜杠，靠 `$uri/index.html` 直接 200 才能与最终 URL 一致。
- **注意**：`src/pages/index.vue` 有上次未提交的首页 TDK/热门搜索改动，本次刻意排除，未混入分页提交。构建耗时大头仍是 2607 routes 预渲染，分页只多 15 页；PWA precache 5904 条 / 165MB 是后续可优化项。
